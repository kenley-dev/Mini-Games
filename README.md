# 🎮 Mini Games

Welcome! This repository features a collection of Python mini-games I built during my Grade 11 introductory programming course. 

These projects were my very first experience with coding and were created using the **CMU Graphics** library. Looking back, the code is far from optimized—but it represents where my programming journey started!

> **Note:** I plan to build a separate repository soon where I recreate these games using my current development skills and cleaner software design practices.

---

## 🕹️ Included Games

| Game | Description | Key Features / Mechanics |
| :--- | :--- | :--- |
| **Pac-Man** | Classic arcade game where you navigate a maze and avoid ghosts. | Grid movement, score tracking, ghost bot |
| **Crossy Road** | Dodge obstacles and traffic to cross as many roads as possible. | Collision detection, endless scrolling, continuous controls |
| **Alien Invaders** | Space shooter where you defend against descending waves of aliens. | Projectile physics, wave management, state tracking |
| **Wordle** | Text-based puzzle game guessing a 5-letter hidden word. | String manipulation, letter-matching logic, limited attempts |
| **Connect Four** | Two-player turn-based board game to connect four tokens in a row. | 2D arrays, win-condition checking, turn switching |
